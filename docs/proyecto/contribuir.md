# Contribuir

InteriorAI es software libre: avisos de fallos, ideas, mejoras de la documentación y código son
bienvenidos.

| Quiero… | Cómo |
|---------|------|
| Avisar de un fallo | [Issue con la plantilla «Avisar de un fallo»](https://github.com/SergioVelmay/InteriorAI/issues/new?template=error.yml) |
| Proponer una mejora | [Issue con la plantilla «Proponer una mejora»](https://github.com/SergioVelmay/InteriorAI/issues/new?template=mejora.yml) |
| Avisar de una vulnerabilidad | En privado, según la [política de seguridad](seguridad.md) |
| Proponer un cambio en el código o la documentación | Fork, rama y Pull Request a `main`, según la [guía de contribución](https://github.com/SergioVelmay/InteriorAI/blob/main/CONTRIBUTING.md) |

!!! warning "Sin secretos"
    Nunca pegues tu `.env`, claves ni endpoints de Azure en una issue, una Pull Request o una
    captura.

No hace falta una cuenta de Azure para contribuir: todo funciona en **modo simulación**, y los
tests y la CI nunca llaman a la IA real. El entorno, las convenciones y las pruebas están en
[Desarrollo](../desarrollo/index.md).

Participar en el proyecto supone aceptar su
[código de conducta](https://github.com/SergioVelmay/InteriorAI/blob/main/CODE_OF_CONDUCT.md)
(Contributor Covenant 2.1).
